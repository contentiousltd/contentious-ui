# Architecture Decision Records

Significant architectural choices for `@contentious/ui`, with context and rationale.

Identifiers carry the `UI` prefix per suite [ADR-0008](https://github.com/contentiousltd/contentious/blob/main/docs/adr/0008-adr-identifier-namespacing.md).
**A bare four-digit `ADR-NNNN` means a family-level decision in the `contentious`
meta-repo, not one of these.** The prefix arrived on 2026-08-09; the numbers are
unchanged, so `ADR-0003` in an older document is this repo's `ADR-UI-0003`.
