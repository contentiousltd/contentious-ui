Extracted · data display patterns

Six patterns, reusable everywhere.

The old page had two competing ways to show a number, five nested slabs, and fire-red on values that meant nothing was wrong. These six patterns replace all of that, and they’re the same ones the Results and Inventory pages need.

Pattern 01Metric
One way to present a number, everywhere in the product. Mono label, value, one line of context – always left-aligned, never centred, so decimals and digit counts line up down a column and across a row. Tabular numerals are mandatory. The label may carry one chip; the value may carry a small unit.
label: mono 10px / .09em
value: Bely Display 30px
tabular-nums, letter-spacing -.01em
sub: 13px gloaming-400
padding: 17px 20px 18px
Pattern 02Metric band
Metrics that share a subject sit in one surface divided by hairlines, not in separate cards with gaps. It reads as a single instrument panel and removes three of the four slab layers the old page had. Three or four per band; five means two bands.
limestone-300, radius 8px
divider: 1px limestone-600
no gaps, no shadows
3–4 columns max
Pattern 03Data colour
Numbers are gloaming-800 by default. Colour is reserved for meaning: sapling when the number is good news, fire when it needs action, gloaming-400 for a genuine zero. The old page rendered every value – including $0.0000 and 0% – in accent red, which spent the alarm colour on nothing and left no way to signal a real problem.
default: gloaming-800
good: sapling-700
bad: fire-600
zero/empty: gloaming-400
never accent-by-default
Pattern 04Section header
A hairline rule with heading, one-line note, and an optional action on the right. Replaces the wrapper slab entirely: the group is defined by the rule above it and the space around it, which costs nothing and stops the page looking like stacked boxes. Bely at 21px, not Display at 34 – Display is for page titles.
Bely 21px / 400
note: 14px gloaming-400
rule: 1px limestone-700
42px above, 18px below
action: 13px fire-650
Pattern 05Composition bar
Any "where did this total go" breakdown is one 9px stacked bar plus an inline legend carrying the values. Cheaper than a donut, reads at a glance, and works down to a 320px column. Cap it at four segments; anything smaller than 5% folds into "Other".
height 9px, radius 5px
track: limestone-600
legend: 13px + mono value
max 4 segments
Pattern 06Micro series
Trend over a small fixed window: bars, wave-400, current period in wave-600. No axes, no gridlines, no tooltips – a shape, not a chart. When someone needs the actual figures they use the metric next to it or the CSV export.
height 54px, gap 5px
bar: wave-400 / wave-600
radius 2px top only
labels: mono 10px

Do

  • Pair every headline number with the figure it’s derived from ("3,074 calls · $0.0134 each")
  • Round to the precision someone can act on – $41.28, not $41.2847
  • Give data sections a real action: export, view failures, settings
  • Put filters in one toolbar above the data, with the freshness stamp beside them
  • Use the chip set for status, so "Failed" looks the same here as in Results

Don’t

  • No centred metric columns – they can’t be compared vertically
  • No slab inside a slab; one surface depth per page
  • No decorative icons on metrics (they were carrying no information)
  • No four-decimal placeholders as a default display format
  • No Sign out in the page header – it lives in the account menu
  • No Bely Display below 30px; use Bely for section headings
